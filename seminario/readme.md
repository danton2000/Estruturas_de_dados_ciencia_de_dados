# O que a apresentação deve conter obrigatoriamente
## Cada grupo deverá abordar, obrigatoriamente, os seguintes pontos:
1. Nome do algoritmo
2. Ideia central de funcionamento
> Explicar, com as próprias palavras, qual é a lógica do algoritmo.
3. Funcionamento passo a passo
>  Mostrar como o algoritmo ordena uma lista pequena, por exemplo: [5, 3, 8, 1, 2].
4. Implementação em Python
5. Explicação do código
>  O grupo deve apresentar o código e explicar sua estrutura principal.
6. Complexidade de tempo
>  Indicar melhor caso, caso médio e pior caso, quando fizer sentido.
7. Vantagens do algoritmo
8. Limitações do algoritmo
9. Situações em que ele faz mais sentido

# Formato esperado da apresentação
## A apresentação deve ser organizada de forma didática. Sugestão de estrutura:
Slide 1: título do algoritmo e nomes dos integrantes
Slide 2: ideia geral
Slide 3: passo a passo com exemplo
Slide 4: implementação em Python
Slide 5: explicação do código
Slide 6: complexidade
Slide 7: vantagens e limitações
Slide 8: conclusão
O grupo pode adaptar essa estrutura, desde que todos os itens obrigatórios sejam contemplados.

# Entregas
## Cada grupo deverá entregar:
1. Os slides da apresentação;
2. O código em Python do algoritmo;
3. Um resumo curto com os principais pontos estudados.
